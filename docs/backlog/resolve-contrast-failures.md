# Resolve the contrast failures

White on the default accent `#4a90e2` is about 3.3:1 and `text-subtle` `#808080` is about 3.9:1; body text needs 4.5:1 in both themes.

## Requirements
- Darken the default accent (and derive hover/subtle from it), or restrict usage and document it.

## Acceptance
- Body text meets 4.5:1 on its ground in light and dark.
